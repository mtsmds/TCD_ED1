# TCD_ED1

Sistema de Gerenciamento de Livros


Compilação

Para compilar o projeto utilizando o Makefile, execute no terminal:

mingw32-make 

Para remover os arquivos gerados pela compilação:

make clean
Execução

Após a compilação, execute o programa com:

./sistema.exe

Uso

Ao iniciar o programa, será exibido um menu no terminal.

O sistema permite:

Cadastrar livros;
Listar e buscar livros;
Alterar o status de leitura;
Navegar entre os livros;
Avaliar livros;
Desfazer ações;
Utilizar o feed de leitura;
Gerenciar metas de leitura.

Para utilizar o sistema, basta selecionar uma opção do menu e seguir as instruções exibidas no terminal.
